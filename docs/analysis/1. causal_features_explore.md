## 2. Pipeline

```
CSV tháng
  → index MS + don_gia = tri_gia / so_luong
  → log-MoM / log-YoY (3 metric)
  → robust_z_causal (shift(1) → rolling median/MAD 12)
  → z_don_gia − z_so_luong
  → lưu CSV causal + vẽ quan sát
```

## 4. No look-ahead — `robust_z_causal`

Công thức cốt lõi:

1. `base = s.shift(1)` — cửa sổ không chứa tháng \(t\)  
2. `med`, `mad` = rolling median / MAD trên `base` (window 12, `min_periods ≥ 3`)  
3. \(z_t = (s_t - med_t) / (1.4826 \cdot mad_t)\)

Hệ số 1.4826 chuẩn hóa MAD về thang gần std dưới giả sử chuẩn.

**Vì sao bắt buộc `shift(1)`?**  
Nếu rolling gồm cả \(x_t\) rồi so \(x_t\) với median đó, điểm spike tự kéo median/MAD → z bị nén → backtest “biết trước” một phần anomaly.

MoM/YoY trên log vốn chỉ dùng \(t\) và \(t-1\) / \(t-12\) — không cần shift thêm.

---

## 5. Vì sao thu gọn 10 cột (không dùng bộ exploratory)

`scripts/1. feature_lag_rolling.ipynb` sinh ~66 cột (lag, nhiều cửa sổ rolling…). Bộ đó hữu ích để khám phá, **không** phù hợp làm input chuẩn IF:

| Lý do | Giải thích |
|---|---|
| Sample ngắn | ~150–200 điểm sau warm-up; nhiều chiều → score không ổn định |
| Rủi ro rò rỉ | Lag/rolling dễ viết sai (không shift) khi copy nhanh |
| Đủ 3 tín hiệu | Thay đổi tương đối + lệch mức + lệch giá–lượng |
| Khớp khuyến nghị PDF | 8–12 feature compact cho proximity AD |

**Cố ý bỏ tạm:** lag 1/2/3/12, tổng 3 tháng, YTD, sin/cos tháng, cờ Tết, residual ETS làm feature — thuộc phase sau (ensemble / exogenous).

## 6. Quan sát từ lần chạy (gạo)

### 6.1. Phân phối

- Log-MoM lượng/trị giá: std ~0.30 — biến động tháng lớn.  
- Log-MoM đơn giá: std ~0.046 — giá ổn định hơn khối lượng.  
- Robust z có đuôi xa (±4…±8) → có tháng lệch mạnh so lịch sử 12 tháng.  
- `z_don_gia_minus_z_so_luong` std ~2.3 — tín hiệu cấu trúc đủ biến thiên để IF học.

### 6.2. Missing

Trên 4 chuỗi XK đủ tháng, tỷ lệ NaN gần giống nhau:

| Nhóm | ~NaN |
|---|---|
| MoM | ~0.5% (tháng đầu) |
| YoY | ~5.7% (12 tháng đầu) |
| Robust z / hiệu z | ~5.2% (warm-up rolling) |

→ Không cần chiến lược impute phức tạp; walk-forward IF chỉ `dropna` theo hàng.

### 6.3. Heatmap (sau bỏ ~24 tháng đầu)

Kỳ vọng: MoM lượng ↔ MoM trị giá tương quan cao; đơn giá tách hơn; hiệu z giá–lượng tương quan âm với z lượng — khớp định nghĩa cột.

Timeline vẽ ±3 như tham chiếu thị giác ngưỡng WARN quen thuộc của tầng ETS (không phải ngưỡng IF).
